# X (Twitter) Post Search / twitter-work-search

---

## Introduction

Search X (Twitter) posts by keyword with one click. Supports multiple search modes — trending, latest, media-rich, and more — delivering tweet content, engagement metrics, media attachments, and author profiles. Ideal for sentiment analysis, market research, and content operations.

**Core Value**

- 🔍 **Precise Search**: Enter a keyword and instantly retrieve relevant X content — no more manual browsing
- 📊 **Comprehensive Data**: Likes, retweets, replies, views — all engagement metrics in one place
- 🎯 **Flexible Modes**: Switch between Trending / Latest / Media / People / Lists — five perspectives for every search intent
- 🧠 **Smart Experience**: Use natural language to trigger searches; automatic pagination requires no manual effort

**Who It's For**

- 📱 Operators — track trending topics in real time and stay on top of public sentiment
- 📈 Marketing Teams — analyze competitor presence and user feedback on X
- 🏷️ Brand Owners — monitor brand mentions and catch opportunities or risks early
- ✍️ Content Creators — discover inspiration and tap into global trending topics

---

## Features

### Core Features

- **Smart Keyword Search**: Enter any keyword to instantly search tweets, users, and lists on X
- **Five Search Modes**: Trending, latest posts, image/video filtering, people search, list aggregation — covering every search intent
- **Tweet Detail Extraction**: Automatically retrieves text, likes, retweets, replies, bookmarks, views, and more
- **Media Attachment Access**: Extracts image covers and video playback URLs from tweets, with multi-resolution support
- **Author Profile Display**: Shows author nickname, follower count, verification status, location, and more
- **Smart Pagination**: Handles pagination automatically — no data gets missed even with large result sets

## Usage Guide

Just describe what you need in natural language — no commands to memorize.

> User: Search trending tweets about "AI" on X
>
> Assistant: Found 20 trending tweets about "AI", sorted by popularity...

> User: What's the latest discussion on "Apple Event"?
>
> Assistant: Found the latest tweets about "Apple Event", 20 in total...

> User: Show me the next page
>
> Assistant: Loading the next page, here are more tweets...

### Quick Reference

| Intent | Example Query | Result |
|--------|--------------|--------|
| Trending | "Search trending Tesla content on X" | Sorted by overall popularity |
| Latest | "Check the latest Bitcoin discussions" | Sorted by publish time (newest first) |
| Images/Videos | "Find pictures and videos about the Paris Olympics" | Filters tweets with media |
| Find People | "Search X for AI-focused accounts" | Returns relevant user profiles |
| Find Lists | "Search for tech-related lists" | Returns relevant lists |
| Next Page | "Next page", "Continue", "More" | Loads additional tweets |
