# X(Twitter)作品搜索

## 📝 简介

X(Twitter)作品搜索工具，帮你快速在 X 平台按关键词精准检索作品。支持热门排序、最新发布、图片视频筛选等多种搜索模式，输出作品正文、点赞转发等互动指标、媒体附件详情及作者画像，为舆情分析、市场调研和内容运营提供数据支撑。

适用场景：运营人员追踪话题热度趋势、市场团队分析竞品动态、品牌方监控舆情声量、内容创作者寻找灵感素材。

## ✨ 功能特性

### 核心功能

| 功能模块 | 能力描述 | 核心价值 |
|---------|---------|----------|
| 关键词智能搜索 | 输入任意关键词，一键检索 X 平台相关推文 | 告别手动浏览，秒级获取目标内容 |
| 五种搜索模式 | 支持热门、最新、媒体、用户、列表五种筛选方式 | 按需切换视角，精准定位所需内容 |
| 推文详情提取 | 自动提取正文、点赞、转发、回复、收藏、浏览等全维度数据 | 数据全面，分析有据可依 |
| 媒体附件获取 | 自动提取推文中的图片封面和视频播放地址 | 内容素材一键获取，支持多清晰度 |
| 作者画像展示 | 同步展示作者昵称、粉丝数、认证状态、所在地等信息 | 快速评估信源质量与影响力 |
| 智能分页翻页 | 自动处理分页逻辑，支持连续翻页获取更多结果 | 数据量大也不遗漏，翻页无感知 |

### 特色亮点

- **搜索模式自由切换**：热门推文、最新动态、图片视频、精准找人、列表聚合，五大模式覆盖所有搜索意图
- **全维度数据输出**：从推文正文到互动数据、从媒体附件到作者画像，一条推文的信息全部到位
- **操作极简**：只需输入关键词，支持口语化表达，自动识别搜索意图并返回结构化结果

## 📖 使用指南

### 🔑 鉴权

前往 [红狐hub](https://redfox.hk/settings/api-keys?source=github) 获取 API KEY

配置方式：
1. 在 `~/.openclaw/openclaw.json` 中配置
2. 设置环境变量 `REDFOX_API_KEY`
3. 使用命令行参数 `--api-key`

### 基础使用

直接告诉我你想搜索的关键词即可：

> 用户：搜一下X上关于"AI"的热门推文
>
> 助手：为你找到 20 条关于"AI"的热门推文，按热度排序如下...

> 用户：看看"苹果发布会"的最新讨论
>
> 助手：为你找到关于"苹果发布会"的最新推文，共 20 条...

> 用户：继续看下一页
>
> 助手：已加载下一页，继续为你展示更多推文...

支持五种搜索类型，如果不指定，默认按**热门**搜索：
- **热门**（Top）：综合热度最高的推文
- **最新**（Latest）：按发布时间倒序
- **媒体**（Media）：包含图片或视频的推文
- **用户**（People）：搜索相关用户账号
- **列表**（Lists）：搜索相关列表

### 常用说法速查

| searchType | 触发关键词 | 示例话术 |
|:---:|---|---|
| **Top**（热门） | 热门、热度、最火、Top | "搜一下X上关于特斯拉的热门内容" |
| **Latest**（最新） | 最新、最近、Latest、新发布 | "看看比特币的最新讨论" |
| **Media**（媒体） | 图片、视频、媒体、Media、照片 | "找一下巴黎奥运相关的图片和视频" |
| **People**（用户） | 用户、账号、找人、People、博主 | "在X上搜一下做AI的账号" |
| **Lists**（列表） | 列表、Lists | "搜一下科技类的列表" |
| —（翻页） | 下一页、继续、还有吗 | 加载更多推文，自动沿用上次的 searchType |

## 🔄 工作流程

1. **接收关键词**：从你的消息中提取搜索关键词和搜索类型偏好
2. **验证输入**：检查关键词是否有效，搜索类型是否在支持范围内
3. **执行搜索**：调用 X 搜索接口，一键获取推文数据
4. **智能翻页**：结果满 20 条时自动提示翻页，支持连续查看
5. **结构化输出**：将推文数据整理为易读的表格，包含正文、互动指标、推文链接和作者信息，媒体附件以图标标记

## ❓ 常见问答

### 使用相关

**Q：支持搜索哪些内容？**
A：支持按关键词搜索 X 平台的推文、用户和列表，覆盖正文、图片、视频等全部内容类型。

**Q：搜索类型怎么选？**
A：想看热度高的选"热门"，想看最新动态选"最新"，只想看图片视频选"媒体"，找人搜账号选"用户"，查列表选"列表"。不指定时默认热门排序。

**Q：一次能看多少条推文？**
A：每次返回最多 20 条，如果结果超过一页，会自动提示你翻页继续查看。

**Q：可以搜非中文关键词吗？**
A：可以，支持任意语言的关键词搜索。

**Q：搜索结果包含哪些信息？**
A：每条推文包含正文、发布时间、点赞/转发/回复/收藏/浏览等互动数据、图片封面和视频地址、以及作者昵称、粉丝数、认证状态等用户信息。

### 故障排除

**Q：搜索返回"未找到相关推文"？**
A：尝试更通用的关键词、减少限定词，或更换搜索类型（如从热门改为最新）。

**Q：提示 API Key 无效？**
A：请前往 [红狐hub](https://redfox.hk/settings/api-keys?source=github) 检查 API Key 是否正确配置，确保密钥有效且未过期。

**Q：翻页提示不出现了？**
A：只有当搜索结果满 20 条时才会出现翻页提示，不足 20 条说明已经是最后一页。
