# X(Twitter)作品搜索 / twitter-work-search

---

## 简介

在 X 平台按关键词一键精准检索作品，支持热门、最新、图片视频等多种搜索模式，输出推文正文、互动数据、媒体附件和作者信息，为舆情分析、市场调研和内容运营提供数据支撑。

**核心价值**

- 🔍 **精准检索**：输入关键词即可秒级获取 X 平台相关内容，告别手动浏览
- 📊 **数据全面**：点赞、转发、回复、浏览等全维度互动指标一站到位
- 🎯 **模式灵活**：热门 / 最新 / 媒体 / 用户 / 列表五种搜索视角自由切换
- 🧠 **智能体验**：口语化表达即可触发搜索，自动翻页无需手动操作

**适用对象**

- 📱 运营人员 — 快速追踪话题热度趋势，掌握一手舆情动态
- 📈 市场团队 — 分析竞品在 X 平台的声量与用户反馈
- 🏷️ 品牌方 — 监控品牌提及情况，及时发现传播机会与风险
- ✍️ 内容创作者 — 寻找灵感素材，了解海外热门话题走向

---

## 功能特性

### 核心功能

- **关键词智能搜索**：输入任意关键词，一键检索 X 平台推文、用户和列表
- **五种搜索模式**：热门排序、最新发布、图片视频筛选、精准找人、列表聚合，覆盖全部搜索意图
- **推文详情提取**：自动获取正文、点赞、转发、回复、收藏、浏览等全维度数据
- **媒体附件获取**：自动提取推文中的图片封面和视频播放地址，支持多清晰度
- **作者画像展示**：同步展示作者昵称、粉丝数、认证状态、所在地等信息
- **智能分页翻页**：自动处理翻页逻辑，数据量大也不遗漏

## 使用指南

直接用自然语言描述需求，无需记忆命令。

> 用户：搜一下 X 上关于"AI"的热门推文
>
> 助手：为你找到 20 条关于"AI"的热门推文，按热度排序如下...

> 用户：看看"苹果发布会"的最新讨论
>
> 助手：为你找到关于"苹果发布会"的最新推文，共 20 条...

> 用户：继续看下一页
>
> 助手：已加载下一页，继续为你展示更多推文...

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|---------|------|
| 热门内容 | "搜一下 X 上关于特斯拉的热门内容" | 按综合热度排序 |
| 最新动态 | "看看比特币的最新讨论" | 按发布时间倒序 |
| 图片视频 | "找一下巴黎奥运相关的图片和视频" | 筛选含媒体的推文 |
| 找人 | "在 X 上搜一下做 AI 的账号" | 搜索相关用户 |
| 查列表 | "搜一下科技类的列表" | 搜索相关列表 |
| 翻页 | "下一页""继续""还有吗" | 加载更多推文 |
