# 快手视频提文案 / kuaishou-text-extract

---

## 简介

通过快手视频链接一键提取口播文案，自动完成提交与获取流程，返回完整文案与带时间戳的分句。支持任务续查，是复刻爆款脚本、生成字幕稿的效率利器。

**核心价值**

- **一键提取**：粘贴视频链接即可自动完成全流程，口播稿一键转文字。
- **完整文案 + 时间戳**：同时返回拼接好的完整文案与逐句时间戳，满足复刻脚本和字幕制作两种需求。
- **任务续查不丢失**：处理中途若超时或中断，可用任务 ID 继续查询，不丢任务。

**适用对象**

- 🔍 **内容创作者** — 复刻爆款视频的口播脚本，拆解选题结构。
- 📊 **运营 / 数据分析** — 快速转写视频内容，评估文案质量。
- 🎬 **剪辑 / 字幕** — 用时间戳分句快速生成字幕稿。

---

## 功能特性

### 核心功能

- **一键提文案**：提交视频链接后自动完成提取流程，口播稿一键转文字。
- **完整文案输出**：返回全部分段拼接的完整文案，可直接用于复刻选题脚本。
- **时间戳分句**：逐句附带精确起止时间，字幕制作和剪辑定位一步到位。
- **任务续查**：支持通过任务 ID 继续查询，中途超时或中断也能找回结果。
- **状态兼容**：兼容多种处理状态，提取过程稳定可靠。

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| -------- | ---------------------------- | -------- |
| 提取视频文案 | 「帮我提取这个快手视频的口播文案」 | 粘贴链接后自动提取，返回完整文案 |
| 获取字幕时间戳 | 「把这个视频的文案加上时间戳给我」 | 返回逐句带时间戳的分句列表，方便做字幕 |
| 续查任务 | 「上次那个视频提取结果帮我查一下」 | 通过任务 ID 继续查询，不丢任务 |
| 复刻爆款脚本 | 「把这个爆款视频的文案提取出来，我要分析结构」 | 获取完整口播稿，辅助脚本拆解与仿写 |

### 输出示例

提取成功后，你将收到：

📝 完整文案如下：

> 视频中这个小孩今年才3岁，他叫苗苗。锅里的青菜在油的包裹下发出滋滋的声响……

同时可选查看逐句时间戳：

| # | 时间区间 | 文案片段 |
|---|---------|---------|
| 1 | 0.20s - 6.72s | 视频中这个小孩今年才3岁，他叫苗苗… |
| 2 | 7.00s - 9.88s | 锅里的青菜在油的包裹下发出滋滋的声响。 |
