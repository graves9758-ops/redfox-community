# 小红书账号深度诊断 / xiaohongshu-account-analyzer

---

## 简介

深度拆解小红书账号，基于真实数据输出七维度量化评分诊断报告与可视化 HTML，帮你一眼看清账号健康度、商业价值和优化方向。

**核心价值**

- 七维度量化评分（满分 100 分），覆盖定位、粉丝、选题、封面、爆文、互动、产能
- 自动推荐 2-5 个相似账号，横向对比找到差距和可学之处
- 一键生成精美 HTML 报告，可导出分享
- 支持多账号对比分析，批量评估创作者矩阵

**适用对象**

- 👤 小红书创作者 — 诊断自己的账号，发现定位模糊、选题迷茫等真实问题
- 🏢 MCN 运营 — 批量评估签约博主，识别潜力账号和需要扶持的账号
- 📈 品牌方 — 筛选合作达人，评估商业价值和粉丝质量
- 🔍 竞品分析 — 拆解竞品账号策略，发现可借鉴的打法

---

## 功能特性

### 核心功能

- 七维度诊断评分：账号定位、粉丝画像与需求、选题体系、封面风格、爆文能力、互动规模、更新产能
- 生命周期分析：判断账号所处发展阶段
- 行动处方生成：基于诊断结果输出可落地的优化建议
- 相似账号推荐：推荐 2-5 个可对比的相似账号
- 多账号对比分析：支持多账号横向对比
- HTML 报告生成：可视化诊断报告，可导出分享

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 单账号诊断 | 分析小红书号 26112666886 | 输出七维度诊断报告，推荐相似账号，生成 HTML 报告 |
| 多账号对比 | 帮我对比分析 ID1 和 ID2 | 分别输出诊断报告 + 横向对比总结 + 生成对比 HTML |
| 分析相似账号 | 回复序号"1"选择相似账号 | 对选中的相似账号进行完整诊断分析 |
