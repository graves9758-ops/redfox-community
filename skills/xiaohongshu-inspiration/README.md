# 小红书内容灵感专家 / xiaohongshu-inspiration

---

## 简介

一个 Skill 覆盖小红书选题灵感全链路 —— 从找爆款、追榜单到选对标，基于红狐数据每日收录的小红书爆款库（互动数 1000 以上收录，每日更新），帮你快速找到下一个选题。

**核心价值**

- **数据驱动选题**：所有推荐均来自每日收录的爆款库，热门笔记、榜单、对标账号都有真实互动数据支撑，告别拍脑袋选题。
- **全链路一站覆盖**：爆款搜索、批量取数、每日榜单、低粉爆款、对标推荐六大能力一个入口，选题灵感不再东拼西凑。
- **小博主友好视角**：专挖粉丝 5000 以下却点赞 500+ 的黑马笔记，起号期也能直接复制的爆款样本。
- **报告一键导出**：查询结果支持 Excel 表格与可视化页面报告，方便在浏览器中查看、分享与复盘。

**适用对象**

- 📝 **小红书创作者** — 追爆款、找选题、学黑马玩法，快速锁定下一个内容方向。
- 📊 **内容运营** — 榜单追踪与批量取数，用数据化方式做选题规划。
- 🏢 **品牌方 / MCN 机构** — 找对标账号、看赛道排名，投放与合作决策有据可依。

---

## 功能特性

### 核心功能

- **关键词爆款搜索**：按关键词搜索爆款笔记（收录标准为互动数 1000 以上），按相关性、热度、时效三维评分排序推荐，附拓词方向建议。
- **关键词批量获取作品**：按关键词 + 日期范围 + 排序方式批量获取作品数据（最近 30 天内），支持导出 Excel 表格与可视化页面报告。
- **每日爆款 TOP50**：查询当日「爆发笔记」榜单 —— 统计笔记发布后第 3 天相对第 2 天的互动增量，附爆款规律分析。
- **低粉爆款挖掘**：挖掘粉丝 5000 以下且点赞 500 以上的黑马笔记 TOP50，附爆款规律分析，适合找选题、学标题写法。
- **账号榜单**：查询日榜 / 周榜 / 月榜账号 TOP50（按总粉丝数与周期内粉丝、点赞、收藏、分享、评论增量加权评分），覆盖 25 个标准赛道。
- **对标账号推荐**：输入账号 ID 或「赛道 + 粉丝数 + 等级」，推荐粉丝量接近、可直接复制玩法的同阶对标，以及粉丝量 3-5 倍、值得参考追赶的高阶标杆。

## 使用指南

直接用自然语言描述你的需求即可，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| --- | --- | --- |
| 搜爆款笔记 | 「搜一下睫毛膏的爆款笔记」 | 三维评分排序的爆款笔记推荐 + 拓词方向建议 |
| 批量取数导出 | 「获取 8 月穿搭作品数据，导出 Excel」 | 指定时间范围的批量作品数据 + Excel / 可视化报告 |
| 查每日爆款榜 | 「今日爆款笔记有哪些」 | 互动增量爆发榜 TOP50 + 爆款规律分析 |
| 挖低粉爆款 | 「找一些粉丝少但很火的笔记」 | 低粉黑马笔记 TOP50 + 规律分析 |
| 查账号榜单 | 「小红书美妆日榜 TOP50」 | 赛道账号榜单 + 综合评分 + 可视化报告 |
| 找对标账号 | 「做饭赛道 3000 粉素人，推荐对标」 | 同阶对标 + 高阶标杆账号推荐 |

### 输出示例

**关键词爆款搜索**：查询时间范围说明 + 数据表格（笔记标题 / 作者 / 互动数 / 发布时间 / 相关性 / 热度 / 时效 / 总分）+ 推荐细分赛道。

**账号榜单**：榜单表格（排名 / 账号名 / 综合评分 / 总粉丝数 / 新增笔记、粉丝、点赞、评论、收藏、分享）+ 排名算法说明 + 可下载的可视化报告。

**对标账号推荐**：同阶对标表格（账号名 / 粉丝数 / 近 30 天互动数 / 推荐理由）+ 高阶标杆表格 + 分析总结。

## 重要数据说明

- 数据覆盖**昨天至 30 天前**，今天的数据暂未入库；互动数据截止入库时间，非实时。
- 各能力更新时间：爆款笔记搜索每日早 7 点更新昨日数据；每日爆款榜每日 19:00 更新；低粉爆款每日 19:30 更新；账号日榜每日 19:00、周榜每周一 15:00、月榜每月 1 日 9:00 更新。
- 账号榜单回溯范围：日榜近 7 天、周榜近 3 周、月榜近 3 个月。
