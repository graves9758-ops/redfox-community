# B站搜索批量下载

> 输入关键词搜遍 B站全站视频，搜索即自动批量获取高清下载链接，让视频采集不再繁琐

---

## 简介

**B站搜索批量下载** 是一款专为内容创作者、品牌运营、市场调研人员设计的 B站视频采集工具。只需输入一个关键词，即可快速搜索 B站全站视频作品，灵活按播放量、点赞数、发布时间等维度排序筛选，搜索完成后自动批量获取全部高清下载链接，告别逐个打开网页手动下载的低效操作。

- **核心价值**：将「搜索 → 筛选 → 下载」三步合一，一次对话完成从发现到采集的全流程，大幅提升视频素材收集效率
- **适用对象**：内容创作者、社媒运营、市场策划、MCN机构、视频剪辑师、竞品分析人员
- **技术基础**：基于红狐数据平台的 B站作品搜索与视频解析能力

---

## 功能特性

### 核心能力

| 功能 | 说明 |
|------|------|
| 关键词搜索 | 输入任意关键词，全站搜索 B站视频作品，支持翻页查看更多结果 |
| 多维排序 | 默认按综合排序排列，同时支持最新发布、最多点赞，可按最近7天/30天/90天/不限筛选发布时间 |
| 灵活翻页 | 搜索结果分页展示，支持前后翻页，每页最多50条结果 |
| 一键批量下载 | 搜索后自动批量获取全部结果的高清下载链接与封面图，一次搜索即完成采集 |
| 高清资源 | 自动解析视频最高可用画质，同时返回视频、音频、封面等多种资源类型 |
| 积分保护 | 搜索前主动提示积分消耗预估，用户确认后执行；下载直接执行，无需二次确认 |

### 特色亮点

- **一句话操作**：说"搜索B站关于XX的视频"即可获取结果，无需记忆复杂命令
- **搜索下载一体**：搜索后自动解析全部视频下载链接与封面图，无需手动逐个获取
- **零缓存设计**：结果仅在对话中展示，不落盘缓存，数据安全可控
- **多资源解析**：同一视频可同时获取视频流、音频流、封面图，满足不同使用场景

## 使用指南

### 鉴权配置

使用本技能前需要配置红狐 API 密钥 `REDFOX_API_KEY`：

1. 访问 [红狐Hub 官网](https://redfox.hk?source=github) 了解服务详情
2. 前往 [注册页面](https://redfox.hk/login?source=github) 注册账号（新用户获赠免费积分）
3. 登录后在 API 密钥管理页面创建密钥，格式为 `ak_xxxxxxxx`
4. 将密钥设置为环境变量 `REDFOX_API_KEY`

环境变量设置方式：

- **macOS/Linux**：在终端执行 `export REDFOX_API_KEY=ak_xxxx`，或追加到 `~/.zshrc` / `~/.bashrc` 后 `source`
- **Windows**：在 PowerShell 执行 `[Environment]::SetEnvironmentVariable("REDFOX_API_KEY", "ak_xxxx", "User")`，重启终端生效

### 触发方式

当用户提到以下任意关键词时自动激活：

- "B站下载"、"下载B站视频"、"B站视频下载"
- "B站找素材"、"B站采集"
- 直接发送 B站视频链接并要求下载

### 输出格式规范

#### 搜索结果输出

搜索结果以 Markdown 表格形式展示，顶部信息栏 + 数据表格：

**顶部查询信息栏**：
- 关键词：「{keyword}」
- 查询结果总数：{total} 条视频
- 排序方式：默认按综合排序
- 发布时间：默认最近7天
- 当前页码：第 {page} 页
- 提示语：「以下是详细数据：」

**数据表格**：

| # | 视频标题 | UP主 | 播放量 | 点赞数 | 评论数 | 收藏数 | 发布时间 | 下载链接 |
|---|----------|------|--------|--------|--------|--------|----------|----------|
| 1 | [视频标题](https://www.bilibili.com/video/BVxxxxxx/) | [UP主名](https://space.bilibili.com/作者ID) | 447.9w | 18.5w | 8301 | 32.7w | 07月31 | [封面图](cover_url) / [视频下载](download_url) |

- 视频标题为可点击链接，跳转至B站视频详情页
- UP主名称为可点击链接，跳转至B站UP主个人空间
- 视频标题和UP主字段中的特殊字符需替换为空字符串
- 播放量/点赞数/收藏数 >= 10000 使用 `x.xw` 格式
- 下载链接列包含封面图链接和视频下载链接，搜索完成后自动获取
- 展示后主动询问：「回复「下一页」查看更多视频。查询约消耗6积分左右，确认积分是否足够。」

> ⚠️ **搜索前积分确认**：执行搜索前，必须先提示用户：
> 「⚠️技能中包含视频下载功能，每条视频作品下载约消耗0.6积分，单次查询10条数据，约消耗10×0.6约6积分。是否执行？
> 回复"是"将会立即查询相关数据」
> 待用户确认后才执行搜索。搜索完成后自动调用下载接口获取全部结果的下载链接。

#### 下载结果输出

下载结果直接整合在搜索数据表格的「下载链接」列中，格式为：

`[封面图]({cover_url}) / [视频下载]({download_url})`

> 详细执行流程、输出格式模板、错误处理请参见 **[核心工作流](references/core_workflow.md)**；接口字段与调用细节参见 **[API接口指南](references/api_guide.md)**

## 常见问答

### 安装相关

**Q1: 提示"未找到 REDFOX_API_KEY"怎么办？**

A: 请参见上方使用指南中的鉴权配置说明设置环境变量。如果不会配置，直接告诉 Agent，它会帮你操作。

**Q2: 需要安装什么依赖？**

A: 不需要。脚本使用 Python 标准库 `urllib`，Python 3.6+ 环境即可直接运行。

---

### 使用相关

**Q3: 一次搜索能返回多少条结果？**

A: 每次搜索返回一页结果，默认每页10条，最大可设置50条。通过翻页可以查看更多结果（每页消耗一次积分）。

**Q4: 下载的视频是什么画质？**

A: 系统自动解析视频的最高可用画质，具体取决于视频本身支持的最高清晰度。

**Q5: 下载链接有效期多久？**

A: 下载链接具有时效性，建议获取后尽快下载。若链接过期，重新执行下载即可获取新链接。

**Q6: 可以同时下载多个视频吗？**

A: 搜索完成后自动获取全部搜索结果的下载链接，无需手动选择。每次搜索最多返回10条结果。

**Q7: 支持哪些排序方式和时间筛选？**

A: 支持三种排序：综合排序（按播放量）、最新发布、最多点赞。默认按播放量降序。时间范围：最近7天（默认）、最近30天、最近90天、不限。

---

### 故障排除

**Q8: 搜索不到想要的视频？**

A: 可能原因：关键词过于生僻；尝试更换更通用的关键词或调整排序方式后重试。

**Q9: 下载失败怎么办？**

A: 可能原因：视频链接有误；视频已被删除或设为私密；网络波动。请检查链接后重试。

**Q10: 提示积分不足？**

A: 每次搜索和下载均消耗一次积分。请前往 [红狐Hub](https://redfox.hk?source=github) 查看积分余额或充值。
