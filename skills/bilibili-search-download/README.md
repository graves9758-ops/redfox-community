# B站搜索批量下载 / bilibili-search-download

---

## 简介

B站搜索批量下载是一款智能视频采集工具，输入关键词即可搜索 B站全站视频，搜索后自动批量获取全部高清下载链接，将「搜索→筛选→下载」三步合一，大幅提升视频素材收集效率。

**核心价值**

- 一个关键词搜遍 B站全站视频，告别逐页手动浏览
- 搜索完成后自动批量获取全部视频下载链接，无需手动选取
- 自动解析最高画质，同时返回视频、音频、封面资源

**适用对象**

- 内容创作者 — 快速搜集视频素材与灵感参考
- 品牌运营 — 监控竞品在 B站的内容动态
- 市场策划 — 调研行业热门话题与内容趋势
- MCN机构 — 批量采集达人视频进行分析
- 视频剪辑师 — 获取高清源文件用于二次创作

---

## 功能特性

### 核心功能

- **关键词搜索**：输入任意关键词全站搜索 B站视频，支持翻页与多维排序（发布时间/播放量/点赞/评论/收藏）
- **自动批量下载**：搜索完成后自动批量获取全部视频下载链接与封面图，无需手动选取
- **高清解析**：自动解析视频最高可用画质，同时返回视频流、音频流、封面图
- **积分保护**：搜索和翻页前主动提示积分消耗，确认后才执行

## 使用指南

直接用自然语言描述需求，无需记忆任何命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|---------|------|
| 搜索视频 | 「搜索B站羽绒服评测视频」 | 按关键词搜索，自动批量获取全部视频下载链接 |
| 排序搜索 | 「按最新发布排序搜索B站手机评测」 | 搜索并按指定维度排序，自动获取下载链接 |
| 翻页 | 「下一页」 | 获取下一页搜索结果，自动获取下载链接 |
| 直接下载 | 「下载 https://www.bilibili.com/video/BVxxx/」 | 通过链接直接获取下载地址 |

### 输出示例

**搜索结果**展示为表格，顶部显示关键词、结果总数、排序方式（默认按播放量降序）、页码，表格包含序号、视频标题、UP主、播放量、点赞数、评论数、收藏数；**下载结果**展示每条视频的标题、封面图、下载链接和资源类型。
