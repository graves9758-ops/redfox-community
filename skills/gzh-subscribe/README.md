# 公众号订阅追踪 / gzh-subscribe

---

## 简介

你的公众号内容雷达。订阅竞对、同类和关注账号，每天早上 6 点自动获取订阅账号的最新发文，以清晰的表格展示发文日期、作者、标题、简介、阅读数、点赞数与原文链接，一键生成可视化日报。

**核心价值**

- **收件箱式订阅**：像订阅 Newsletter 一样订阅公众号，最多 20 个，按「竞对 / 同类 / 关注」三类分组管理。
- **每日准时推送**：一键开启定时任务，每天 06:00 自动生成精排日报并打开浏览器，像收邮件一样看公众号。
- **关键数据一屏尽览**：发文日期、标题、简介、阅读数、点赞数一表呈现，原文链接一键直达。
- **双模式阅读**：终端实时查表，可视化日报适合分享与存档。

**适用对象**

- 📊 **品牌 / 市场运营** — 盯梢竞对公众号动态，第一时间掌握对手选题与动作。
- ✍️ **内容创作者** — 追踪同类账号与行业大号，持续获取选题灵感与写作参照。
- 🔍 **行业研究者** — 把关注账号的每日发文沉淀为日报，便于归档与回顾。

---

## 功能特性

### 核心功能

- **订阅管理**：添加、取消、查看订阅，最多 20 个公众号；账号 ID 支持 account / wxId / bizInfo 三种格式，提供任意一种即可。
- **三类分组**：「竞对账号」盯对手、「同类账号」找灵感、「关注账号」追大神，日报按分组展示。
- **每日发文获取**：一次拉取所有订阅账号的最新发文，包含标题、作者、简介、阅读数、点赞数、发布时间与原文链接。
- **可视化日报**：自动生成精美日报页面，按分组排版并自动打开浏览器，便于分享与存档。
- **每日自动推送**：一键开启每天 06:00 定时推送，自动生成当日日报；也可随时取消。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图         | 示例话术                                                     | 效果                                   |
| ------------ | ------------------------------------------------------------ | -------------------------------------- |
| 订阅公众号   | 「帮我订阅红狐数据这个公众号，ID 是 redfoxdata1，归到关注账号」 | 加入订阅列表，后续可随时拉取发文       |
| 查看订阅     | 「看看我现在订阅了哪些公众号」                               | 按分组列出全部订阅账号                 |
| 拉取发文     | 「拉一下我订阅的公众号最新发文」                             | 终端表格展示各账号最新文章与数据       |
| 生成日报     | 「帮我生成今天的公众号日报」                                 | 生成可视化日报并自动打开浏览器         |
| 每日自动推送 | 「开启每天早上 6 点的公众号推送」                            | 安装定时任务，每天自动生成并打开日报   |
| 取消订阅     | 「取消订阅红狐数据」                                         | 从订阅列表中移除该账号                 |

### 输出示例

拉取发文后，终端表格按账号依次展示每篇文章的发文日期、作者、标题、简介、阅读数、点赞数与原文链接；同时生成一份可视化日报，按「竞对 / 同类 / 关注」分组排版，适合分享与存档。

## 重要数据说明

- 数据来自红狐广域库，覆盖范围广；采用 T+1 更新，每日拉取前一天及近 7 天的发文。
- 订阅上限为 20 个公众号；每次拉取按订阅数消耗数据额度，建议开启每日自动推送，而非频繁手动拉取。
- 如确认账号 ID 正确但广域库中仍查不到目标账号，可联系红狐数据获取定制支持：redfoxdata@proton.me。
