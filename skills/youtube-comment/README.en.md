# YouTube Comment Analyzer / youtube-comment

---

## Introduction

YouTube Comment Analyzer is an intelligent comment insight tool. Simply paste any YouTube video link to instantly retrieve comment data and four-dimensional sentiment analysis, quickly capturing authentic user feedback beneath any video.

**Core Value**

- Skip manual comment scrolling — a single query delivers a full comment list with sentiment breakdown
- Four-dimensional sentiment view (Positive/Negative/Demand/Competitor) rapidly identifies public sentiment trends and user needs
- Supports batch queries and pagination for flexible analysis depth

**Target Users**

- 📊 Brand Operators — Monitor public sentiment on brand-related videos, detect reputation risks early
- 📈 Social Media Managers — Evaluate content performance, optimize strategy with data-driven insights
- 🎯 Marketing Planners — Analyze competitor video feedback to identify differentiation opportunities
- 💡 Product Managers — Discover authentic user needs to guide product iteration decisions

---

## Features

### Core Features

- **Comment Retrieval**: Paste a video link to pull comment data; supports multi-link batch queries
- **Paginated Fetching**: Continue fetching the next page of comments for deeper analysis
- **Four-Dimensional Sentiment Analysis**: Intelligent per-comment tagging, delivering Positive/Negative/Demand/Competitor ratios with representative comment excerpts
- **Comment Sorting**: Sort by top or newest, with language and region preference filtering
- **Multi-Language Support**: Covers videos in all languages, understanding hashtags, @mentions, and emojis in original context
- **Credit Protection**: Proactively prompts credit consumption before batch queries and pagination, executing only after confirmation

## Usage Guide

Describe your needs in natural language — paste a link to get a complete analysis without memorizing any commands.

### Quick Reference

| Intent | Example Prompt | Result |
|--------|---------------|--------|
| View video comments | "Analyze https://www.youtube.com/watch?v=xxx" | Video info + comment list + four-dimensional analysis |
| Query by video ID | "Check comments for video sa8AzBK4dao" | Auto-identifies ID and retrieves comments |
| Continue to next page | "Next page" | Fetches the next page of comments |
| Batch query | Paste multiple links at once | Retrieves and analyzes each video independently |

### Output Preview

Results are presented in a fixed four-section format:

1. **Video Info**: Video ID, link, query parameters
2. **Query Scope**: Summary of comments retrieved in this batch
3. **Comment List**: Like-sorted comment table (user, content, engagement metrics)
4. **Four-Dimensional Sentiment Analysis**: Positive/Negative/Demand/Competitor ratios with representative comments
