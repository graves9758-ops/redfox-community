# YouTube视频评论分析 / youtube-comment

---

## 简介

YouTube视频评论分析是一款智能评论洞察工具，输入任意 YouTube 视频链接，即可一键获取评论数据与四维情感分析结果，快速掌握视频下的用户真实反馈。

**核心价值**

- 告别逐条翻阅评论，一次查询即可获得评论全量列表与情感占比分析
- 四维情感视角（积极/负面/需求/竞品）快速定位舆情风向与用户诉求
- 支持批量查询与翻页续查，灵活覆盖不同分析深度

**适用对象**

- 📊 品牌运营 — 监测品牌相关视频的公众态度，及时发现舆情风险
- 📈 社媒运营 — 复盘内容传播效果，数据驱动内容策略优化
- 🎯 市场策划 — 分析竞品视频用户反馈，找准差异化方向
- 💡 产品经理 — 挖掘真实用户需求，指导产品迭代决策

---

## 功能特性

### 核心功能

- **评论获取**：粘贴视频链接即可拉取评论数据，支持多链接批量查询
- **翻页续查**：支持继续获取下一页评论，满足深度分析需求
- **四维情感分析**：逐条评论智能打标，输出积极/负面/需求/竞品四维度占比与代表性评论
- **评论排序**：支持按热门或最新排序，可按语言和地区偏好筛选
- **多语言支持**：覆盖各语种视频评论，基于原文语境理解 hashtag、@提及与表情符号
- **积分保护**：批量查询与翻页前主动提示积分消耗，确认后才执行

## 使用指南

直接用自然语言描述需求，粘贴链接即可获得完整分析，无需记忆任何命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|---------|------|
| 查看视频评论 | 「查询 https://www.youtube.com/watch?v=xxx」 | 获取视频信息 + 评论列表 + 四维分析 |
| 通过视频ID查询 | 「查看视频 sa8AzBK4dao 的评论」 | 自动识别ID并拉取评论 |
| 继续翻页 | 「下一页」 | 获取下一页评论 |
| 批量查询 | 一次粘贴多条链接 | 逐一拉取并独立分析每条视频 |

### 输出示例

查询结果按固定四板块展示：

1. **视频信息**：视频ID、链接、查询参数
2. **查询范围**：本次获取评论条数说明
3. **评论列表**：按点赞排序的评论表格（含用户、内容、互动数据）
4. **四维情感分析**：积极/负面/需求/竞品占比与代表评论
