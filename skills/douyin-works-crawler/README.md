# 抖音作品爬取 / douyin-works-crawler

---

## 简介

抖音作品数据获取工具，输入抖音号（纯字母/字母+数字/纯数字），通过红狐API广域库一键获取账号基础信息与近期作品内容列表（支持分页，最多 50 条/页），含互动数据和作品直达链接，并提供互动 TOP3 分析与账号特征总结，帮助用户快速掌握目标账号的内容表现。中文昵称暂不支持查询，输入时将引导改用抖音号。

**核心价值**

- **一键获取作品数据**：输入抖音号（纯字母/字母+数字/纯数字），自动获取账号昵称、抖音号、UID、粉丝数、作品总数等基础信息及近期作品列表。
- **数据亮点自动分析**：互动量 TOP3 作品分析 + 账号特征总结（更新频率、内容方向、互动表现、爆款特征），快速发现值得学习的内容。
- **作品直达链接**：每条作品提供直达链接，点击即可跳转查看原视频。

**适用对象**

- 🏢 **品牌方 / 营销经理** — 监测竞品抖音账号的内容表现和互动数据。
- 🛍️ **MCN / 运营人员** — 快速评估达人账号的数据表现和内容方向。
- 📝 **抖音内容创作者** — 学习同领域头部账号的爆款内容特征。
- 📊 **数据分析师** — 批量获取结构化数据用于分析报告。

---

## 功能特性

### 核心功能

- **账号信息查询**：输入抖音号，一键获取账号基础数据（昵称、抖音号、UID、粉丝数、作品总数）。
- **近期作品获取**：自动获取近期作品列表（支持分页，最多 50 条/页），包含点赞、评论、分享、收藏、互动数及作品直达链接。
- **数据亮点分析**：输出互动量 TOP3 作品分析 + 账号特征分析（更新频率、内容方向、互动表现、爆款特征）。

### 特色亮点

- **中文昵称拦截**：所有输入统一使用 uniqueName 参数查询；检测到中文昵称时直接阻断（不发起 API 调用），引导用户提供抖音号。
- **直达链接**：昵称可跳转账号主页，每条作品提供直达链接。
- **安全可靠**：通过数据服务接入，无需登录抖音账号。

- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 重要数据说明

- 作品列表为近期作品数据，支持分页（最多 50 条/页），按发布时间倒序排列，非账号全部历史作品；账号历史作品总数为接口 `total` 字段。
- 互动数为手动计算：点赞 + 评论 + 分享 + 收藏。
- 作品直达链接来自接口 `opusUrl` 字段。
- 账号基础信息从作品项的 `author*` 字段提取，无独立账号信息接口。
- 数字格式：≥1 万显示为 `x.xw`（如 3.2w），≥1 亿显示为 `x.x亿`，<1 万用千分位逗号。
- 暂不支持中文昵称查询（中文昵称不唯一，且广域库对昵称收录率低）。请使用抖音号查询：抖音APP → 目标账号主页 → 昵称下方，支持纯字母（如 luoyonghao）、字母+数字（如 18561019369wn）、纯数字（如 50734407794）三种类型。
- 所有数据唯一来源为红狐数据API（广域库），广域库仅收录热门数据，部分账号可能暂不在库；不会从第三方渠道补充或估算。
> 💼 另外红狐配套全量数据库可提供完整详实数据，如需了解采购方案，可前往红狐hub[企业服务](https://redfox.hk/dashboard/enterprise)对接咨询

## 数据来源

- **唯一数据源**：红狐数据API（广域库）
- **查询接口**：`POST https://redfox.hk/story/api/dy/data/listWorkByAccount`
- **认证方式**：请求头 `X-API-KEY`（环境变量 `REDFOX_API_KEY`，格式 `ak_xxx`）
- **数据范围**：近期作品数据，支持分页（最多 50 条/页），广域库仅收录热门数据
