# WeChat Content Workshop / wechat-creator

---

## Introduction

An all-in-one tool covering the full WeChat Official Account creation and operations workflow — combining **7 core capabilities**: 100k+ Viral Article Rankings, Viral Article Writing, Title Generation + Scoring, Copy Rewriting, Prohibited Word Detection, Cover Design, and Account Diagnosis. Powered by RedFoxHub's daily collection of **1,000+ articles with 100k+ reads** and cross-platform WeChat viral content data, turning raw inspiration into publish-ready deliverables.

**Core Value**

- **Data-driven creation**: Massive daily-updated viral content data ensures every title, article, and cover design is backed by real trends — no more guesswork.
- **End-to-end coverage in one place**: From topic inspiration (viral rankings) to final publishing (article + title + cover + compliance check) — a single entry point handles it all.
- **Compliance assurance**: Built-in prohibited word detection with risk-level tagging automatically flags sensitive expressions before publishing.

**Who It's For**

- 📝 **WeChat Account Operators** — Track daily 100k+ viral content trends and quickly internalize topic and title patterns.
- ✍️ **Content Creators** — Go from viral pattern insights to fully publishable articles in one flow, with high output efficiency.
- 🏢 **Brands / MCN Agencies** — Produce differentiated articles at scale across accounts, paired with diagnostic benchmarking to refine content strategy.
- 📊 **Operations Editors / Viral Content Researchers** — Multi-dimensional account diagnosis + cross-category viral research to build data-driven operations plans.

## Features

### Core Capabilities

- **100k+ Viral Article Rankings**: Query daily 100k+ read TOP50 articles across all categories or within 23 standard classifications, with four-dimension content analysis, viral pattern summaries, and exportable visual reports.
- **Viral Article Writing**: Search same-category viral content by keyword, extract traffic drivers and structural patterns, blend in personal style samples, and generate a complete publish-ready article.
- **Title Generation + Scoring**: Generate 10 candidate titles based on viral data patterns (with match score and recommendation rationale), or score an existing title on a four-dimension 100-point scale.
- **Copy Rewriting**: Transform any source material into WeChat viral content style in one click; rewriting records are automatically submitted (free, no credits consumed).
- **Prohibited Word Detection**: Supports four input methods — plain text, file upload, image, and webpage URL — with risk-level tagging, replacement suggestions, and a safe-to-publish output version.
- **Cover Design**: Analyze visual patterns from same-category viral covers and output 3 differentiated 2.35:1 landscape design proposals, each with an actionable image-generation prompt.
- **Account Diagnosis**: Four-dimension 100-point scoring + S/A/B/C/D/E six-tier rating + industry benchmarking, with support for multi-account horizontal comparison.

## Usage Guide

Describe what you need in plain language — no commands to memorize.

### Quick Reference

| Intent | Example Prompt | Outcome |
| --- | --- | --- |
| Check viral rankings | "Show me today's 100k+ viral articles" | Full-category or category-specific viral rankings with pattern analysis |
| Write a WeChat article | "Write me a WeChat article about changing jobs" | Viral pattern insights + style blending + publish-ready full article |
| Generate viral titles | "Give me 10 WeChat title options" | 10 candidate titles + match scores + recommendation rationales |
| Evaluate a title | "Score this title for me" | Four-dimension 100-point score + per-dimension breakdown + optimization tips |
| Rewrite copy | "Rewrite this paragraph in WeChat viral style" | WeChat viral-style rewrite, auto-submitted (free) |
| Detect prohibited words | "Scan this article for prohibited words" | Risk-level tagging + replacement suggestions + safe version |
| Design a cover | "Design a cover for this article" | 3 design proposals based on same-category viral cover patterns |
| Diagnose an account | "Diagnose the XX WeChat account" | Four-dimension score + six-tier rating + industry benchmark + optimization tips |

### Output Examples

**100k+ Viral Article Rankings**: Full ranking table (rank / title / author / read count) + four-dimension analysis per article (content overview / trend leverage / sharing driver / achieved effect) + viral pattern summary.

**Title Scoring**: Composite score (e.g. 85/100) + tier (S/A/B/C) + four-dimension breakdown (category match / click-trigger strength / structural compliance / viral potential match) + strength analysis and optimization tips.

**Prohibited Word Detection**: Flagged words bolded in original text → replacement suggestion per flagged word → safe-to-publish version output.
