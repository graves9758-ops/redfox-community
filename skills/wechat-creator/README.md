# 公众号内容工坊 / wechat-creator

---

## 简介

公众号创作与运营全链路一站式工具 —— 聚合 **10w+ 爆文榜单、爆款正文创作、标题生成+评分、文案改写、违禁词检测、封面设计、账号诊断** 七大能力，基于红狐数据每日收录的 **1000+ 条 10w+ 爆文**与全网公众号爆款数据，把灵感打磨成可直接发布的成品。

**核心价值**

- **数据驱动创作**：基于每日更新的海量爆款数据，标题、正文、封面均有据可依，告别拍脑袋。
- **全链路一站覆盖**：从选题灵感（爆文榜单）到成品发布（正文+标题+封面+合规检测），一个入口搞定。
- **合规保障**：内置违禁词检测与风险分级标注，发布前自动排查敏感表述。

**适用对象**

- 📝 **公众号运营者** — 每日追踪 10w+ 爆文风向，快速掌握选题与标题套路。
- ✍️ **内容创作者** — 从爆款规律提炼到完整文章一键生成，高效产出可发布内容。
- 🏢 **品牌方 / MCN 机构** — 矩阵批量产出差异化文章，搭配诊断对标优化内容策略。
- 📊 **运营编辑 / 爆文研究者** — 多维度账号诊断 + 跨赛道爆文调研，制定数据化运营方案。

---

## 功能特性

### 核心功能

- **10w+ 爆文榜单**：按 23 个标准分类或全领域查询每日 10w+ 阅读文章 TOP50，附四维度内容分析与爆款规律总结，支持可视化页面导出。
- **爆款正文创作**：关键词检索同赛道爆款，提炼流量密码与结构规律，融合个人风格样本，生成可直接发布的完整文章。
- **标题生成+评分**：基于爆款数据规律生成 10 个候选标题（附匹配指数与推荐理由），或对已有标题做四维百分制量化评分。
- **文案改写**：将任意素材一键转为公众号爆款风格，改写记录自动上报（免费，不扣积分）。
- **违禁词检测**：支持文案、文件、图片、网页四种输入方式，风险分级标注 + 替换建议 + 安全版本输出。
- **封面设计**：分析同赛道爆款封面视觉规律，输出 3 套 2.35:1 横版设计方案，含可落地的生图提示词。
- **账号诊断**：四维度 100 分制评分 + S/A/B/C/D/E 六级评级 + 行业对标，支持多账号横向对比。

- 请前往 [红狐 hub](https://redfox.hk?souce=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述你的需求即可，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| --- | --- | --- |
| 查爆文榜单 | 「看看今天的 10w+ 爆文」 | 全领域或指定赛道爆文榜单，附爆款规律分析 |
| 写公众号文章 | 「帮我写一篇关于职场跳槽的公众号文章」 | 爆款规律提炼 + 风格融合 + 可发布完整文章 |
| 起爆款标题 | 「帮我起 10 个公众号标题」 | 10 个候选标题 + 匹配指数 + 推荐理由 |
| 评估标题 | 「这个标题打几分」 | 四维百分制评分 + 各维度明细 + 优化建议 |
| 改写文案 | 「把这段话改成公众号风格」 | 公众号爆款风格改写，自动上报（免费） |
| 检测违禁词 | 「帮我扫一下这篇文章的违禁词」 | 风险分级标注 + 替换建议 + 安全版本 |
| 设计封面 | 「为这篇文章设计一个封面」 | 基于同赛道爆款封面规律的 3 套设计方案 |
| 诊断账号 | 「诊断一下 XX 公众号」 | 四维度评分 + 六级评级 + 行业对标 + 优化建议 |

### 输出示例

**10w+ 爆文榜单**：完整榜单表格（序号 / 标题 / 作者 / 阅读数）+ 每篇文章四维度分析（内容概述 / 热点利用 / 传播作用 / 达成效果）+ 爆款规律总结。

**标题评分**：综合评分（如 85 分/100 分）+ 等级（S/A/B/C）+ 四维度明细（赛道匹配度 / 点击诱因强度 / 结构合规性 / 爆文潜质匹配度）+ 优势分析与优化建议。

**违禁词检测**：原文命中词加粗标出 → 每个违禁词配替换建议 → 输出可直接发布的安全版本。
