# Core Workflow

## 工作流程

### Step 0：鉴权前置检查

脚本会自动从环境变量 `REDFOX_API_KEY` 获取 API Key，若未设置则尝试从 shell 配置文件读取，仍找不到则提示用户配置后退出。

### Step 1：调用账号搜索脚本

```bash
python3 ~/.workbuddy/skills/kuaishou-account-search/scripts/search_ks_user.py "<账号名称>" [--page 页码] [--size 每页条数]
```

**参数说明：**

| 参数 | 必填 | 含义 |
|------|------|------|
| `account_name` | 是 | 快手账号名称（模糊搜索关键词，如：人民日报） |
| `--page` | 否 | 页码，从 1 开始（默认：1） |
| `--size` | 否 | 每页条数（默认：20，最大 50） |

脚本以 JSON 格式输出：

| 字段 | 说明 |
|------|------|
| `users` | 搜索到的账号列表 |
| `total` | 总数 |
| `page` | 当前页码 |
| `page_size` | 每页条数 |
| `has_next` | 是否有下一页（true/false） |

每条账号字段：

| 字段 | 说明 |
|------|------|
| `nickname` | 账号昵称（为空显示 `-`） |
| `kwai_id` | 快手账号平台展示 id（kwaiId，null 转空串） |
| `signature` | 账号简介 |
| `head_url` | 头像 URL |
| `cover_img_url` | 封面图 URL |

### Step 2：展示搜索结果

> 📊 关键词「**XXX**」搜索到 **N** 个账号（第 {page} 页），以下是候选列表：

```markdown
| # | 账号昵称 | kwaiId | 账号简介 |
|---|---------|--------|---------|
| 1 | 人民日报 | rmrbxmtzx | 参与、沟通、记录时代。 |
| 2 | 人民日报国际 | lingshichapd | 敬请关注"人民日报国际"... |
```

- **账号简介**超长时截断为 40 字并在末尾加 `...`
- **kwaiId 为空**（接口返回 null）的账号：无法查询作品，标注为「—」，并提示该账号暂无可查作品
- 若有下一页（`has_next` 为 true）：> 📄 当前第 **{page}** 页。回复「下一页」继续查看。

### Step 3：引导用户确认

> 请回复序号或账号名，我将继续查询该账号的作品列表。（若只想看作品，可直接说「查第 1 个」或「查人民日报的作品」）

> ⚠️ 若搜索结果中没有目标账号，提示用户：可尝试更换更短/更精确的名称关键词，或直接提供账号主页链接 / kwaiId。

### Step 4：无结果情况

> 😔 抱歉，未查询到账号「**XXX**」。
> 💡 建议尝试：更换更短/更通用的关键词，或直接提供账号主页链接。

### Step 5：数据时效说明

> ⏰ 数据每日早上 **06:00** 更新（广域库快照）。
