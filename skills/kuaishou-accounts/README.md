# 快手账号搜索 / kuaishou-account-search

---

## 简介

通过快手账号名称模糊搜索定位目标账号，一键获取账号昵称、头像、简介及 `kwaiId`，`kwaiId` 可直接用于查询该账号的全部作品列表。

**核心价值**

- **名称即搜即得**：输入账号名称关键词即可搜索，无需精确 ID，输入「人民日报」就能找到目标账号。
- **完整账号画像**：返回昵称、头像、封面、简介，快速判断账号定位与内容方向。
- **一键联动作品查询**：搜索到的 `kwaiId` 可直接传给作品查询 skill，无缝跳转到作品列表。
- **分页浏览**：每页最多 50 条，支持多页翻看，同名或相似账号不遗漏。

**适用对象**

- 🔍 **内容创作者** — 搜索同赛道账号，快速锁定对标目标。
- 📊 **运营 / 数据分析** — 快速定位目标账号并获取其 `kwaiId`，衔接后续作品分析。
- 🏢 **品牌 / MCN** — 筛查潜在合作达人，评估账号影响力。

---

## 功能特性

### 核心功能

- **名称模糊搜索**：输入账号名称关键词即可搜索，支持「人民日报」「美食」等灵活查询。
- **返回 kwaiId**：每个账号返回平台展示 ID，直接用于作品列表查询。
- **完整账号画像**：昵称、头像、封面、简介一览无余，快速了解账号定位。
- **分页浏览**：每页最多 50 条，支持逐页翻看，同名账号全部覆盖。

- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| -------- | ---------------------------- | -------- |
| 按名称搜账号 | 「帮我搜一下快手上叫人民日报的账号」 | 返回匹配的账号列表，含昵称、kwaiId、简介 |
| 找达人账号 | 「帮我找一下美食领域的快手达人」 | 通过关键词搜索相关账号，获取 kwaiId 和账号信息 |
| 获取 kwaiId | 「帮我查一下这个博主的 kwaiId」 | 返回目标账号的平台展示 ID，用于后续作品查询 |
| 翻页查看 | 「下一页」 | 继续查看更多搜索结果，不遗漏候选账号 |

### 输出示例

搜索「人民日报」后，你将收到格式化的账号列表：

| # | 账号昵称 | kwaiId | 账号简介 |
|---|---------|--------|---------|
| 1 | 人民日报 | rmrbxmtzx | 参与、沟通、记录时代。 |
| 2 | 人民日报国际 | lingshichapd | 敬请关注"人民日报国际"... |

每个账号包含昵称、kwaiId、简介、头像和封面图，kwaiId 可直接用于查询该账号作品列表。
