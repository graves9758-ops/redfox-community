# 小红书爆款内容创作专家 / xiaohongshu-creator

---

## 简介

一个 Skill 覆盖小红书创作全链路 —— 笔记生成、文案改写、标题生成与评分、封面设计、违禁词检测，把灵感打磨成可直接发布的成品。

**核心价值**

- **五合一创作工具**：笔记、改写、标题、封面、合规检测，一个入口覆盖小红书创作全链路。
- **数据驱动**：基于每日持续收录的 2000+ 条爆款笔记库分析规律，告别凭感觉创作。
- **即拿即用**：输出可直接发布的成品内容，无需二次加工。

**适用对象**

- 📝 **小红书博主** — 从选题到发布一站式创作，告别灵感枯竭。
- 🛍️ **品牌 / 电商运营** — 产品文案快速改写，批量产出投放素材。
- 🏢 **MCN / 内容策划** — 矩阵账号批量产出差异化内容，提升运营效率。

---

## 功能特性

### 核心功能

- **笔记生成**：输入关键词检索同赛道爆款，提炼流量密码后生成带标题、正文、Tags 的完整笔记。
- **文案改写**：任意素材一键转为小红书风格，含标题、emoji、Tags，口语化自然表达。
- **标题生成**：生成 10 个爆款标题，每条附匹配指数、参考爆款与推荐理由。
- **标题评分**：对已有标题做六维加权评分（S/A/B/C 级），给出优化建议与修改版本。
- **封面设计**：AI 分析同赛道爆款封面视觉规律，输出 3 套差异化设计方案与生图提示词。
- **违禁词检测**：支持文案/文件/图片/网页四种输入，标记违禁词并提供替换建议与安全版本。

## 使用指南

直接用自然语言描述你的创作需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 写笔记 | 「帮我写一篇关于防晒霜的小红书笔记」 | 检索爆款 → 分析规律 → 生成完整笔记 |
| 改文案 | 「把这段产品介绍改写成小红书风格」 | 一键转为小红书风文案，含标题和 Tags |
| 起标题 | 「帮我起 10 个关于穿搭的爆款标题」 | 先分析再创新，输出 10 条带评分的标题 |
| 评标题 | 「这个标题帮我打个分：秋冬大衣这样穿」 | 六维评分 + 等级 + 优化修改版本 |
| 做封面 | 「设计一个美妆类小红书封面」 | AI 分析爆款封面 → 输出 3 套设计方案 |
| 查违禁词 | 「帮我看看这篇笔记有没有违禁词」 | 标记问题词 + 替换建议 + 安全版本 |
