# 小红书爆款内容创作专家

## 1. 简介

小红书爆款内容创作专家 —— 一个入口覆盖小红书创作全链路：**笔记生成 / 文案改写 / 标题生成+评分 / 封面设计 / 违禁词检测**。

基于红狐数据每日持续收录的 **2000+ 条爆款笔记数据**，把灵感打磨成可直接发布的成品：

| # | 能力 | 一句话说明 |
|---|------|-----------|
| 1 | 笔记生成 | 关键词检索爆款 → 提炼流量密码 → 生成带标题+正文+Tags 的完整笔记 |
| 2 | 文案改写 | 任意素材一键转为小红书风格，含标题 / emoji / Tags |
| 3 | 标题生成+评分 | 生成 10 个爆款标题，或对已有标题做六维加权评分 |
| 4 | 封面设计 | AI 分析同赛道爆款封面视觉规律，输出 3 套差异化设计方案 |
| 5 | 违禁词检测 | 文案 / 文件 / 图片 / 网页四端输入，加粗标记+替换建议+安全版本 |

**适用对象**：小红书创作者、内容运营、品牌方、MCN 机构。

## 3. 全局规则（所有模块共享）

### 3.1 鉴权（REDFOX_API_KEY）

所有模块共用同一个 API Key。

**获取方式**：
1. 访问 [红狐Hub](https://redfox.hk/?source=github) 了解服务
2. 前往 [注册页](https://redfox.hk/login?source=github) 注册（新用户赠免费积分）
3. 在个人中心获取 API Key，格式 `ak_xxxxxxxx`

**配置方式**（按优先级从高到低）：

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 环境变量 `REDFOX_API_KEY` | 直接读取当前进程环境变量 |
| 2 | Shell 配置文件 | 自动扫描 `~/.zshrc` `~/.bashrc` `~/.bash_profile` `~/.profile` `~/.zprofile` |
| 3 | 提示用户配置 | 以上都找不到时，引导用户配置 |

**配置示例**：
- macOS/Linux（zsh）：`echo 'export REDFOX_API_KEY=ak_xxx' >> ~/.zshrc && source ~/.zshrc`
- macOS/Linux（bash）：写入 `~/.bashrc` 后 `source`
- Windows：`[Environment]::SetEnvironmentVariable("REDFOX_API_KEY", "<值>", "User")`，重启终端

配置后应验证：`echo $REDFOX_API_KEY`（macOS/Linux）/ `echo %REDFOX_API_KEY%`（Windows）。

### 3.2 用词规范（强制）

| ❌ 禁止使用 | ✅ 正确表述 |
|---|---|
| 爬取 / 抓取 | 获取 / 查询 |
| 爆炸封面 / 爆炸数据 | 爆款封面 / 爆款数据 |

所有对外输出（对话、报告、提示词）均须遵守。

### 3.3 关键词类型判断（M1/M3 共用）

- **细分词/垂直赛道**（含场景/属性修饰，如"职场穿搭"、"减脂餐"）→ 直接查询
- **具体产品词**（如"防晒霜"、"睫毛膏"）→ 直接查询，**不扩展到其他形态**（霜≠喷雾≠衣；液≠霜≠气垫）
- **泛化词/大分类**（纯大类词无修饰，如"穿搭"、"美妆"）→ 执行泛化词拓展策略

泛化词拓展：先查询近 7 天网页资讯，生成 10 个细分方向（趋势词、人群词、场景词、意图词各 2-3 个），输出后**停止**等待用户回复「拓展」或「不拓展」。

### 3.4 数据时间规则

- 数据源仅覆盖**昨天至 30 天前**，今天数据未入库
- 用户说"今天/今日"：提示"今天数据暂未更新，已为您展示最近可用数据"
- 超出 30 天：提示"仅支持最近 30 天数据"
- **数据不足自动扩展**（禁止换词）：近 1 天 → 近 3 天 → 近 7 天 → 近 30 天

## 4. M1 笔记生成

### 4.1 触发

"帮我写一篇关于 XX 的小红书笔记"、"生成 XX 相关的文案"。

> ⚠️ 本模块仅在主 Agent 中执行，**不派发给子 Agent**。

### 4.2 执行流程

**Step 1：查询爆款笔记**

关键词处理：
- 无赛道关键词（如"最近热门笔记有哪些"）→ `--keyword ""`
- 细分词/垂直赛道 → 直接搜索
- 泛化词 → 先推荐 10 个细分方向，等待用户选择

时间范围：默认近 7 天（`startDate = 今天 - 7 天`），数据不足自动扩展。

```bash
python scripts/fetch_xhs_hot_articles.py \
  --keyword "<关键词>" \
  --max-items 50 \
  --page-size 50 \
  --start-date "<yyyy-MM-dd>"
```

脚本输出 JSON 到 stdout，含 `items`、`latestHotArticles`、`relatedSearches`，字段说明见 `references/xhs_hot_article_format.md`。

> 禁止把原始爆款数据展示给用户；禁止只发文件路径或"已保存"等简短提示。

**Step 2：分析爆款规律**

基于 50 条数据深度分析：
- 标题规律：高互动标题特征（数字、情绪词、人群标签）、长度与结构
- 内容规律：主题方向、结构与段落分布、互动引导
- 标签策略：高频标签、热门话题标签
- 数据维度：互动总量 / 收藏率 / 评论量 / 点赞比 / totalScore 排序

**Step 3：引导用户上传个人风格参考（必问）**

> "想让我更懂你的风格？发几段平时的笔记、日记或随笔给我就行"

- 提供样本 → 分析风格并融合
- 不提供 → 直接基于爆款规律生成

**Step 4：生成文案**

准备：
1. 回顾爆款规律：高频关键词（必融入）、热门标题模式（必遵循）、结构特征
2. 用 `web_search` 搜索 `小红书 + <选题> + 最新`，获取 1-2 个最新热点作为素材

撰写：
1. **标题**：严格遵循爆款模式，优先数字/疑问/感叹，≤20 字
2. **正文**：融入高频关键词 + 爆款开头"钩子" + 最新热点 + 分点/步骤/对比结构 + 互动收尾 + 少量 Emoji
3. **Tags**：5-10 个相关标签（仅用于正文，不渲染到图片）

**Step 5：输出前自检（必须）**

- [ ] 推荐标题：3-6 个
- [ ] 完整可发布的正文
- [ ] 推荐标签：5-10 个
- [ ] 爆款公式来源 - 参考的爆款规律
- [ ] 爆款公式来源 - 参考的爆款笔记：2-3 篇，含标题 / 作品链接 / 作者名 / 作者链接 / 完整互动数据

### 4.3 输出格式（严格）

```
### 推荐标题
1. [标题1]
2. [标题2]
3. [标题3]

### 正文内容
[完整可发布的正文]

### 推荐标签
#标签1 #标签2 #标签3 #标签4 #标签5

### 爆款公式来源
**参考的爆款规律**：[简述爆款公式，如"数字型标题 + 痛点开场 + 分点干货 + 互动收尾"]

**参考的爆款笔记**（2-3 篇核心参考，优先互动数据最高）：
1. [笔记标题](noteLink) - [@作者名](authorLink) - 互动数据：收藏 X / 分享 X / 评论 X / 点赞 X
2. ...
```

**禁止输出**：卡片设计或图片、脚本命令、文件路径/下载链接、仅展示数据而不生成文案。

## 6. M3 标题生成与评分

### 6.1 触发

- **M3-A 标题生成**："帮我起标题"、"生成爆款标题"、"关于 XX 的标题"
- **M3-B 标题评分**："评分"、"打分"、"这个标题怎么样"、"评估标题"

### 6.2 M3-A 标题生成流程

**Step 1：提取关键词**（遵循全局规则 3.3）

**Step 2：查询数据**

- 默认近 7 天（startDate = 今天 - 7 天），数据不足自动扩展
- 命令：

```bash
python scripts/fetch_xhs_trends.py --keyword "<关键词>" --start-date <yyyy-MM-dd>
```

- 多关键词逗号分隔：`--keyword "防晒霜,防晒喷雾"`
- 全站热门：`--keyword ""`
- **必须向用户汇报数据获取数量**（读 stderr，如"共获取爆款数据 XX 条，其中低粉爆款 XX 条、点赞最多 XX 条、单日互动 XX 条、7 日增长 XX 条"）
- 脚本生成 `关键词_爆款数据.md`，读取用于分析

**Step 3：内部分析（不展示）→ 生成 10 个标题（展示）**

- 先内部分析爆款标题的结构/关键词/情绪/人群/痛点/利益承诺（**不展示**）
- 再基于规律创新生成 10 个标题（非直接复用）
- 标题 ≤20 字
- 匹配指数 8.0-10.0，一位小数，同一指数最多重复 2 次
- 参考爆款必须带链接：`[标题](https://www.xiaohongshu.com/explore/{photoId})`

### 6.3 M3-A 输出格式（严格）

标题列表前必须输出数据说明：
> ⚠️数据说明：！！！受小红书风控规则限制，部分作品链接可能无法正常跳转，您可复制对应作品标题前往小红书搜索查看，感谢理解🙇‍♀️🙇‍♀️

每个标题：
```
**标题X：[标题内容]**
📈匹配指数：[8.0-10.0]
🔥参考的爆款：[标题1](https://www.xiaohongshu.com/explore/{photoId})（互动数：XXX）、[标题2](...)（互动数：YYY）
👍推荐理由：[详细推荐理由]

---
```

### 6.4 M3-B 标题评分流程

**Step 1：识别核心要素**：待评分标题 + 主题关键词（用户未提供则从标题提取）

**Step 2：查询数据**：默认近 30 天（startDate = 今天 - 30 天），命令同 M3-A，必须汇报数据获取数量

**Step 3：六维加权评分**

- **重合判定**：与爆款标题完全一致（或仅标点/空格差异）→ 直接 S 级（9.5+）
- **六维度权重**：主题匹配度 15% / 结构合规度 20% / 利益清晰度 25% / 情绪唤醒度 20% / 稀缺性感知 15% / 合规安全性 5%
- **等级**：S(9.0+) / A(7.0-8.9) / B(5.0-6.9) / C(<5.0)
- 评分公式与输出模板见 `references/title_score_guide.md`

**Step 4：输出优化建议**

- **S 级**：基于六维度说明为什么好 + 3-5 条同主题高赞标题及相似处
- **A/B/C 级**：核心问题清单 + 3-5 条参考爆款 + 2-3 个修改版本（干货风/情绪风/猎奇风，标注适用场景与预期效果）

> 评分结果（综合得分、等级、六维度明细表）必须完整输出，不得省略。

## 8. M5 违禁词检测

### 8.1 触发

"有没有违禁词"、"检测敏感词"、"小红书合规"、"限流词"、"种草文案合规"。

### 8.2 输入方式

| 输入形态 | 执行动作 |
|---|---|
| 纯文本 | 计算字数 → 字数闸门 → `--content="..."` → 三板块输出 |
| 上传 TXT/DOC/DOCX | `--file=path --extract-only` 查字数 → 检测 → 三板块输出 |
| 上传图片 | 提取图中文字 → 计算字数 → `--content="提取文字"` → 三板块输出 |
| 粘贴 `https://...` | `--url=... --extract-only` 查字数 → 检测 → 三板块输出 |
| 超长文案（>3000 字） | **先询问**，收到明确回复后再继续 |

`--content`、`--file`、`--url` 三者互斥。

> ⚠️ PDF 不支持，需转为图片或文本后上传。

### 8.3 执行命令

```bash
python scripts/check_sensitive_words.py --content "<文案>"
python scripts/check_sensitive_words.py --file "<路径>" [--extract-only]
python scripts/check_sensitive_words.py --url "<网址>" [--extract-only]
```

脚本 API Key 优先级：环境变量 → Shell 配置文件 → 提示。完整执行规程（输出模板、格式铁律、示例）见 `references/prohibited_word_core_workflow.md`。

### 8.4 输出三板块

1. 🔍 **违禁词检测结果**：原文中命中词加粗标出
2. 💡 **修改建议**：每个违禁词配上下文替换词 + 理由
3. ✏️ **优化文案**：替换后的可发布版本 + 纯文本文件卡片

### 8.5 高级

- `--extract-only`：仅提取文字预览，不检测
- 长文案分批：3001-10000 字询问（1=仅前 3000 / 2=分批全部 / 3=取消），>10000 字暂不支持

## 11. 常见问答

**Q1: 五个能力都要装吗？**
A: 是的。安装一次即拥有全部 5 个能力，按需路由。若只想用其中一个能力，其他模块的依赖（如 playwright）可不安装，对应模块调用时会提示缺失。

**Q2: API Key 收费吗？**
A: M2 改写记录上报完全免费、不扣积分；M1/M3/M4/M5 的数据查询和违禁词检测会按红狐Hub标准消耗积分，新注册用户赠免费积分可直接使用。

**Q3: 为什么 M1 不能派发给子 Agent？**
A: 笔记生成依赖完整上下文（爆款规律 + 风格样本 + 最新热点）做长链路创作，子 Agent 会丢失上下文，影响输出完整性。

**Q4: 数据时间范围是多少？**
A: 数据库覆盖昨天至 30 天前。M1 默认近 7 天、M3-A 默认近 7 天、M3-B 默认近 30 天、M4 默认近 30 天。

**Q5: 违禁词检测能保证 100% 准确吗？**
A: 基于红狐Hub违禁词库，仅供参考。请结合企业经营范围和产品实际效果核对，最终以小红书平台审核结果为准。

**Q6: 封面方案能直接用吗？**
A: 每个方案含生图提示词，可直接用于 AI 绘图工具生成 1080×1440 封面图。

**Q7: 笔记/作者链接跳转失败？**
A: 小红书对第三方跳转有风控，链接正确也可能被拦。建议复制标题到小红书 App 内搜索查看。

## 12. 使用场景

1. **新手创作者全流程**：选题 → M1 生成笔记 → M4 设计封面 → M5 检测违禁词 → 安心发布
2. **品牌投放文案打磨**：M2 改写产品说明书 → M3-A 起 10 个标题 → M3-B 评分选最优
3. **MCN 矩阵批量产出**：M1 按细分关键词批量生成差异化笔记，M4 为每位达人匹配不同封面风格
4. **运营内容合规抽查**：M5 粘贴落地页 URL 一键检测
5. **旧笔记诊断优化**：把表现差的旧笔记喂给 M2 重写，再用 M3-B 评估新标题
