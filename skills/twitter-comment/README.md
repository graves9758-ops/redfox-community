# X(Twitter)作品评论分析 / twitter-comment

---

## 简介

输入任意推文链接或推文ID，一键获取评论数据，通过四维情感分析快速了解用户真实反馈，生成可离线保存的交互式 HTML 报告。专为社交媒体运营、品牌方、市场研究人员和内容创作者设计。

**核心价值**

- 📊 一键获取推文详情和全部一级评论数据
- 🤖 AI 自动完成四维情感分析（积极/负面/需求/竞品），理解多语言推文语境
- 📋 生成 X 暗黑主题交互式 HTML 报告，便于保存与分享
- 🔒 多链接查询前主动提示积分消耗，确认后才执行

**适用对象**

- 📱 品牌运营 — 快速了解公众态度，及时应对舆情
- 🛒 市场策划 — 了解竞品优劣势，找准差异化方向
- ✍️ 社媒运营 — 了解受众反馈，优化内容策略
- 📊 产品经理 — 挖掘真实需求，指导产品迭代

---

## 功能特性

### 核心功能

- **评论获取**：粘贴推文链接或推文ID即可拉取评论数据，支持一次提交多条链接批量查询
- **多语言支持**：支持各语种推文评论，AI 分析基于原文语境
- **四维 AI 分析**：积极/负面/需求/竞品四类情感分析，各维度附代表评论引用
- **推文详情展示**：作者信息、推文内容、互动数据（点赞/转发/引用/回复/收藏/浏览）全量展示
- **HTML 报告**：X 暗黑主题交互式报告，支持离线保存与分享
- **积分保护**：多链接查询前主动提示积分消耗，确认后才执行

### 特色亮点

- **多语言语境理解**：识别 hashtag、@提及、表情符号及不同语种的表达习惯
- **数据完整展示**：推文详情、评论表格全量呈现，不截断关键信息
- **编码安全回填**：智能编码保障，中文分析内容完整无误地注入报告

## 使用指南

直接用自然语言说出推文链接或推文ID即可，无需记忆固定命令。

### 推文ID获取方式

推文ID可从推文链接中直接提取。例如：

- 推文链接：`https://x.com/jiroucaigou/status/2080273986794184815`
- 推文ID：`2080273986794184815`（即链接中 `/status/` 后面的数字部分）

支持 `x.com` 和 `twitter.com` 两种域名格式。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|---------|------|
| 查看推文评论 | 「查看推文 2076962843841470561 的评论」 | 获取推文详情 + 全部评论 + AI分析 |
| 通过链接查询 | 粘贴 `https://x.com/username/status/2076962843841470561` | 自动提取推文ID并拉取评论 |
| 批量查询 | 一次粘贴多条链接 | 提示积分消耗确认后，逐一拉取并独立分析 |
| 生成报告 | 「需要」「生成HTML」 | 生成交互式HTML报告 |

### 多链接查询

支持一次性提交多条推文链接，检测到多条链接时会先提示积分消耗，确认后逐一执行。每条推文独立展示评论数据和四维分析结果。

### 输出示例

完成查询后，你将依次收到：

1. **推文详情**（作者信息含可点击主页链接、推文内容、互动数据）
2. **评论表格 TOP 10**（按热度排序的前10条评论，含用户链接、内容、互动数据）
3. **四维情感分析**（积极/负面/需求/竞品，各附代表评论）
4. **询问是否生成 HTML 报告**
