# X(Twitter)作品评论分析 / twitter-comment

---

## 简介

X(Twitter)作品评论分析是一款智能评论洞察工具，输入任意推文链接或推文ID，即可一键获取评论数据并通过四维情感分析快速了解用户真实反馈。

**核心价值**

- **一键获取**：粘贴推文链接即可拉取全部一级评论数据，支持批量查询多条推文
- **智能分析**：自动完成积极/负面/需求/竞品四维情感分析，理解多语言推文语境
- **可视化报告**：生成 X 暗黑主题交互式 HTML 报告，支持离线保存与分享

**适用对象**

- 📊 **品牌运营** — 快速了解推文舆论走向，及时应对公众反馈
- 🏢 **市场策划** — 分析竞品推文的用户评论，找准差异化方向
- ✍️ **社媒运营** — 复盘内容传播效果，了解受众真实反馈
- 🔍 **产品经理** — 挖掘话题下的用户需求，指导产品迭代

---

## 功能特性

### 核心功能

- **评论获取**：粘贴推文链接或推文ID即可拉取评论数据，支持一次提交多条链接批量查询
- **多语言支持**：支持各语种推文评论，分析基于原文语境理解
- **四维情感分析**：积极/负面/需求/竞品四类情感分析，各维度附代表评论引用
- **推文详情展示**：作者信息、推文内容、互动数据（点赞/转发/引用/回复/收藏/浏览）全量展示
- **HTML 报告生成**：X 暗黑主题交互式报告，支持离线保存与分享
- **智能积分提醒**：多链接查询前主动提示积分消耗，确认后才执行

## 使用指南

直接用自然语言说出推文链接或推文ID即可，无需记忆固定命令。

### 推文ID获取方式

推文ID可从推文链接中直接提取。例如：

- 推文链接：`https://x.com/jiroucaigou/status/2080273986794184815`
- 推文ID：`2080273986794184815`（即链接中 `/status/` 后面的数字部分）

支持 `x.com` 和 `twitter.com` 两种域名格式。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|---------|------|
| 查看推文评论 | 「查看推文 2076962843841470561 的评论」 | 获取推文详情 + 全部评论 + AI分析 |
| 通过链接查询 | 粘贴 `https://x.com/username/status/2076962843841470561` | 自动提取推文ID并拉取评论 |
| 批量查询 | 一次粘贴多条链接 | 提示积分消耗确认后，逐一拉取并独立分析 |
| 生成报告 | 「需要」「生成HTML」 | 生成交互式HTML可视化报告 |

### 多链接查询

支持一次性提交多条推文链接，检测到多条链接时会先提示本次查询所需积分数，用户确认后才逐一执行。每条推文独立展示评论数据和四维分析结果。

### 输出示例

完成查询后，你将依次收到：

1. **推文详情**（表格形式：作者信息含可点击主页链接、推文内容、作品链接、互动数据）
2. **查询范围**（该推文总评论数与实际获取条数）
3. **评论列表 TOP 10**（按热度排序的前 10 条评论，表格含用户链接、内容、互动数据、时间）
4. **四维情感分析**（积极/负面/需求/竞品四维度，表格含占比与分析）
5. **询问是否生成 HTML 报告**
