# 快手账号作品查询 / kuaishou-account-works

---

## 简介

快手账号作品查询工具，覆盖账号作品列表与单条作品详情两大场景，一次性获取播放、点赞、评论、收藏、分享等完整互动数据，助你全面掌握目标账号与爆款作品的表现。

**核心价值**

- **双场景覆盖**：既能按账号拉取全部作品列表，又能精查单条作品详情，一个工具满足两种需求。
- **数据维度全**：播放数、点赞数、评论数、收藏数、分享数、转发数、视频时长、封面与视频链接一览无余。
- **分页浏览**：每页最多 50 条，支持多页翻看，不遗漏任何一条内容。

**适用对象**

- 🔍 **内容创作者** — 拆解对标账号作品结构、深挖单条爆款，研究爆款规律。
- 📊 **运营 / 数据分析** — 摸清账号更新频率与流量趋势，精确追踪单条作品表现。
- 🏢 **品牌 / MCN** — 筛查合作达人的作品表现，评估单个合作作品的实际价值。
- 🛒 **电商选品** — 查看带货账号的最新作品，匹配推广方向。

---

## 功能特性

### 核心功能

- **双 ID 查询**：支持账号平台展示 ID 或主页链接 ID 两种方式定位账号，有链接或 ID 均可查。
- **账号作品列表**：精准匹配该账号全部可见作品，按发布时间倒序展示，一次拉取完整作品库。
- **单条作品详情**：通过作品 ID 精确查询单条作品的完整数据，深挖爆款背后的指标。
- **完整互动数据**：播放、点赞、评论、收藏、分享、转发、视频时长，全面评估作品表现。
- **分页浏览**：每页最多 50 条，支持逐页翻看，大量作品也不会遗漏。
- **作品直达**：直接输出封面与视频链接，可快速查看或下载原片。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| -------- | ---------------------------- | -------- |
| 按账号查作品列表 | 「帮我查一下人民日报的快手作品」 | 返回该账号全部作品，含播放、点赞等数据，按时间倒序展示 |
| 按 ID 查作品列表 | 「查 kwaiId 为 rmrbxmtzx 的快手作品」 | 通过账号平台展示 ID 精准定位并返回作品列表 |
| 查单条作品详情 | 「帮我看看这个快手作品的数据，ID 是 xxx」 | 返回该作品的完整互动数据与正文信息 |
| 深入研究爆款 | 「分析一下这条爆款作品的各项数据」 | 精查单条作品的所有指标，辅助复盘与选题研究 |
| 翻页查看 | 「下一页」 | 继续查看后续作品，不遗漏任何内容 |

### 输出示例

查询账号作品列表后，你将收到格式化的数据表格：

| # | 作品标题 | 播放数 | 点赞数 | 评论数 | 收藏数 | 发布时间 |
|---|---------|--------|--------|--------|--------|---------|
| 1 | [作品标题](视频链接) | 65.5w | 1.2w | 305 | 8.7w | 2026-07-29 21:46:58 |

每条作品包含标题、作者、粉丝数、播放/点赞/评论/收藏/分享/转发数据、视频时长、封面与视频链接，支持翻页浏览。
