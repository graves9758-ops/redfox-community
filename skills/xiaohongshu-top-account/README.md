# 小红书热门账号推荐 / xiaohongshu-top-account

---

## 简介

想看小红书哪些账号最火、涨粉最猛？直接说品类就能查日榜、周榜、月榜 TOP50，覆盖美妆、美食、旅行、母婴等 25 个赛道，排名数据每日更新，自动生成可视化报告。

**核心价值**

- **榜单全面不遗漏** — 日榜/周榜/月榜三大周期，综合全部或细分赛道，TOP50 账号一目了然。
- **品类精准不跑偏** — 说"美食"自动匹配美味佳肴赛道，说"健身"锁定体育锻炼，模糊词也能识别。
- **报告直观可导出** — 自动生成精美 HTML 报告，支持一键导出 PDF/高清图片，账号名可直接跳转主页。
- **订阅推送不操心** — 设置每日/每周/每月定时推送，榜单数据自动送到你面前。

**适用对象**

- 📊 **品牌/MCN 运营** — 快速锁定各赛道头部达人，为投放和合作提供数据支撑。
- 📝 **小红书博主** — 了解同赛道热门账号动态，找到对标和学习对象。
- 🔍 **内容研究者** — 跨品类、跨周期对比账号表现，洞察平台流量趋势。

---

## 功能特性

### 核心功能

- **排名查询**：查日榜、周榜、月榜 TOP50，默认展示 TOP20，追问即可查看全部。
- **品类筛选**：支持 25 个赛道精准查询（美妆、美食、旅行、母婴、健身等），说赛道名自动匹配。
- **可视化报告**：每次查询自动生成 HTML 报告，账号名可点击跳转主页，支持导出 PDF。
- **定时订阅**：设置推送周期（每日/每周/每月），榜单数据定时送到你面前。
- **历史回溯**：日榜回溯近 7 天，周榜近 3 周，月榜近 3 个月。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
|------|----------|------|
| 查综合日榜 | "小红书最新日榜" | 返回全品类昨日 TOP20 账号排名 |
| 查品类周榜 | "美食周榜" | 返回美味佳肴赛道上周 TOP20 |
| 查月榜 | "美妆月榜" | 返回化妆美容赛道上月 TOP20 |
| 查看全部 | "看全部50条" | 展开完整 TOP50 榜单并交付报告 |
| 下载报告 | "下载报告" | 生成并交付 HTML 可视化报告文件 |
| 订阅推送 | "订阅每日榜单" | 设置每日定时推送榜单数据 |

### 输出示例

查询后你会收到结构化的榜单表格，包含排名、账号名（可点击跳转主页）、综合评分、总粉丝数、新增笔记/粉丝/点赞/评论/收藏/分享等指标，并自动附带 HTML 报告文件。
