# 快手作品搜索 / kuaishou-search

---

## 简介

输入关键词就能搜到快手热门作品（广域库），支持按排序方式多维度筛选，作品标题、作者、播放数、点赞数、评论数、收藏数一览无余，点一下链接就能跳转看详情，还可关联提取视频详情和文案。

**核心价值**

- **即搜即看**：输入任意内容关键词，立刻获取按点赞数排序的爆款作品列表。
- **数据全面**：每条作品展示播放数、点赞数、评论数、收藏数、视频时长及可跳转的作品链接，发布时间精确到时分秒。
- **多维筛选**：支持按综合、最新、点赞、收藏等多种维度排序，灵活切换视角发现好内容。
- **视频详情提取**：每条作品的 work_id 可用于 kuaishou-video-extract 技能获取视频详情和提取视频文案。

**适用对象**

- 🔍 **内容创作者** — 追踪同赛道爆款，为选题与创作提供数据参考。
- 📊 **运营 / 数据分析** — 快速了解某个品类在快手上的热门内容，掌握流量趋势。
- 🏢 **品牌 / MCN** — 筛选潜在合作达人，按互动量评估作品价值，辅助投放决策。
- 🛒 **电商选品** — 搜索细分赛道的带货作品，找到匹配的推广内容方向。

---

## 功能特性

### 核心功能

- **关键词搜索**：输入关键词搜索快手热门作品（广域库），精准发现目标赛道内容。
- **多维排序**：支持综合排序、最新发布、最多点赞、最多收藏四种排序方式。
- **分页浏览**：每页展示 50 条结果，支持多页翻看，不遗漏任何内容。
- **可点击链接**：作品标题以超链接格式输出，一键跳转查看原作品。
- **视频详情提取**：每条作品的 work_id 可用于 kuaishou-video-extract 技能获取视频详情和提取视频文案。

## 使用指南

直接用自然语言说出你想查的内容方向即可，无需记忆固定命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 搜索某类内容 | "搜一下美食内容" | 以“美食”查询作品，按点赞排序 |
| 指定排序方式 | "看看播放最多的世界杯作品" | 以“世界杯”查询，按点赞排序 |
| 切换排序条件 | "按综合排序重新搜索" | 切换排序为综合排序 |
| 翻页查看更多 | "下一页" | 自动递增页码，展示后续 50 条作品 |
| 提取视频详情 | "查看第3条作品的视频详情" | 通过 work_id 调用 kuaishou-video-extract 技能 |
