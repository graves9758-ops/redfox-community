# TikTok 主页视频批量提取 / tiktok-home-downloader

---

## 简介

输入 TikTok 账号主页链接，自动拉取账号主页作品并解析无水印下载链接，支持一键批量下载到本地。

**核心价值**

- **无水印直链**：解析后的视频链接已去除 TikTok 水印，可直接用于二次创作或备份。
- **批量高效**：一次输入主页链接，自动完成作品拉取、链接解析、文件下载全流程。
- **灵活筛选**：支持按发布时间范围、分页浏览，精准定位目标作品。

**适用对象**

- 🎬 **内容创作者** — 收藏学习竞品账号的优质内容，逐帧拆解拍摄与剪辑技巧。
- 📦 **运营 / MCN** — 批量备份达人合作作品，快速完成背调分析。
- 🎓 **知识学习者** — 离线囤积教程类视频，随时反复观看。

---

## 功能特性

### 核心功能

- **作品拉取**：通过主页链接获取账号主页作品，包含标题、播放量、互动数据和作品链接。
- **链接解析**：逐条解析视频的无水印下载直链，支持视频与封面资源。
- **批量下载**：一键下载全部作品到本地，视频和图文均支持。
- **分页浏览**：支持翻页查看更多作品，每页最多 50 条。
- **日期筛选**：按作品发布时间范围精确筛选，支持自然语言识别（如「最近一周」「7月份的作品」）。
- **多账号支持**：可同时输入多个 TikTok 账号，批量处理。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 下载单个账号视频 | 「帮我下载 https://www.tiktok.com/@tiktok 的 TikTok 视频」 | 拉取主页作品并解析下载链接 |
| 批量下载多个账号 | 「把 @tiktok 和 @khaby.lame 的视频都下载下来」 | 多账号依次拉取并下载 |
| 按时间筛选 | 「下载这个账号 7 月份的作品」 | 自动识别日期范围，精准筛选 |
| 查看更多作品 | 「继续看下一页」 | 翻页获取更多作品 |

### 账号输入方式

| 输入格式 | 示例 | 说明 |
| ---- | ---- | ---- |
| 主页链接 | `https://www.tiktok.com/@tiktok` | 推荐，自动解析账号标识 |
| @handle | `@tiktok` | 主页链接中 `@` 后面的部分 |
| secUserId | `MS4wLjABxxxx...` | 可直接使用 |

> 注意：请提供**账号主页链接**，不要提供单条视频链接（含 `/video/` 的链接）。

### 如何获取 secUserId

secUserId 是 TikTok 内部的账号标识，固定以 `MS4w` 开头。当主页链接无法解析（如网络受限、页面反爬）时，提供 secUserId 可以直接查询：

1. **手机 App 分享链接（推荐）**：打开 TikTok App → 进入账号主页 →「分享」→「复制链接」。分享链接中自带 `sec_uid=MS4w...` 参数（形如 `https://www.tiktok.com/@xxx?sec_uid=MS4wLjABAAAA...`），直接把完整链接发给技能即可。
2. **开发者工具**：主页按 `F12` → Console 执行 `JSON.parse(document.getElementById('__UNIVERSAL_DATA_FOR_REHYDRATION__').textContent).__DEFAULT_SCOPE__['webapp.user-detail'].userInfo.user.secUid`，直接打印出 secUserId。

> ⚠️ **分享链接需要带上 `sec_uid=MS4w...` 参数**。普通主页链接（不含 `sec_uid=` 参数）需要访问 TikTok 页面才能解析，可能失败；带参数的分享链接无需访问页面，成功率最高。

> 若提供的 secUserId 格式不正确，技能会自动返回上述获取指引，按方法重新获取即可。

### 输出示例

解析完成后，你将看到类似以下格式的作品表格（示意）：

| # | 发布时间 | 作品 | 播放 | 赞 | 评论 | 收藏 | 分享 | 资源下载 |
|---|----------|------|------|-----|------|------|------|------|
| 1 | 07-28 | [作品标题](链接) | 88.9w | 5.7k | 274 | 322 | 20 | 🎬视频 · 🖼封面 |

表格底部会显示可下载作品数和失败数，并提示是否批量下载到本地。
